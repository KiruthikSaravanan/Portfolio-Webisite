01 / Problem

Investigation context
is hard to carry forward.

Security investigations generate incidents, indicators, relationships and response knowledge. This project explores how that context can be organized for reuse in later investigations; it does not claim enterprise deployment.

02 / Approach

Connect the records.

Bring incident records, IOCs, investigations and ATT&CK techniques into one structured security-memory model, with related context available for review.
